# App Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Разделить `App.svelte` на тестируемый оркестратор и мелкие презентационные компоненты, сохранив поведение.

**Architecture:** `src/lib/sorter/controller.ts` (чистая логика, зависимости внедрены, состояние через `onSnapshot`) + презентационные компоненты в `src/lib/components/`; `App.svelte` остаётся wiring-слоем для auth/sync и разметки.

**Tech Stack:** Svelte 5 runes, TypeScript, bun:test, Tailwind v4 токены.

**Spec:** `docs/superpowers/specs/2026-11-23-app-split-design.md`

## Global Constraints

- Bun только; точные версии зависимостей; `bun run validate` — gate перед завершением задачи.
- Svelte 5 runes только; `$props()`; keyed `{#each}`; русские строки UI, английские комментарии.
- Цвета только токены из `src/app.css`; не добавлять hex/сырые цвета.
- ZIP-контракт, worker и sync-протокол не меняются; при выключенной синхронизации ноль запросов к `/api`.
- `src/lib/sorter/controller.ts` — клиентский модуль, не импортирует `server/` и `@huggingface/transformers`.
- Покрытие новых чистых модулей ≥90% lines/functions.

## Review Focus

1. Очистка object URL при повторном архиве и на `dispose()` → тест в Task 1.
2. Снимок меток на момент старта batch (изменение textarea посередине не влияет) → тест в Task 1.
3. Повторный выбор того же файла / блокировка во время busy → тест в Task 1 + browser в Task 3.
4. Отсутствие `/api`-запросов при выключенной синхронизации после резки → тест и browser в Task 3.

### Task 1: Sorter controller

**Files:** Create `src/lib/sorter/controller.ts`, `src/lib/sorter/controller.test.ts`.

**Interfaces (exact):**
```ts
export type SorterItem = { id: number; ms: number; name: string; scores: Score[]; url: string };
export type ArchiveView = {
  url: string; name: string;
  counts: { sorted: number; skipped: number; errors: number };
  failures: { source: string; error: string }[];
};
export type SorterSnapshot = {
  items: SorterItem[];
  pending: number;
  failure: string | null;
  progress: { loaded: number; total: number } | null;
  percent: number;
  loadingModel: boolean;
  archiveProgress: ArchiveProgress | null;
  archivePercent: number;
  archiveResult: ArchiveView | null;
  archiveBusy: boolean;
  busy: boolean;
};
export type SorterDeps = {
  classify(file: Blob, labels: string[]): Promise<{ scores: Score[]; ms: number }>;
  sortArchive(file: File, labels: string[], classify: ClassifyImage, onProgress: (p: ArchiveProgress) => void): Promise<SortArchiveResult>;
  createUrl(blob: Blob): string;
  revokeUrl(url: string): void;
  now(): number;
  uuid(): string;
  onSnapshot(snapshot: SorterSnapshot): void;
};
export type SorterController = {
  classifyFiles(files: readonly File[], labels: string[]): Promise<void>;
  sortArchiveFile(file: File, labels: string[]): Promise<SyncRun | null>;
  dispose(): void;
};
export function createSorterController(deps: SorterDeps): SorterController;
```
