# App Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split `App.svelte` into a testable orchestrator and small presentational components, preserving behavior.

**Architecture:** `src/lib/sorter/controller.ts` (pure logic, injected dependencies, state via `onSnapshot`) + presentational components in `src/lib/components/`; `App.svelte` remains the wiring layer for auth/sync and markup.

**Tech Stack:** Svelte 5 runes, TypeScript, bun:test, Tailwind v4 tokens.

**Spec:** `docs/superpowers/specs/2026-11-23-app-split-design.md`

## Global Constraints

- Bun only; exact dependency versions; `bun run validate` is the gate before a task is done.
- Svelte 5 runes only; `$props()`; keyed `{#each}`; English UI strings and comments.
- Colors only from the tokens in `src/app.css`; do not add hex or raw colors.
- The ZIP contract, worker and sync protocol are unchanged; zero requests to `/api` when sync is off.
- `src/lib/sorter/controller.ts` is a client module: it imports neither `server/` nor `@huggingface/transformers`.
- Coverage of new pure modules ≥90% lines/functions.

## Review Focus

1. Cleanup of object URLs on a repeated archive and on `dispose()` → test in Task 1.
2. Snapshot of labels at batch start (editing the textarea mid-run has no effect) → test in Task 1.
3. Re-selecting the same file / locking while busy → test in Task 1 and browser check in Task 3.
4. No `/api` requests with sync off after the split → test and browser check in Task 3.

### Task 1: Sorter controller

**Files:** Create `src/lib/sorter/controller.ts`, `src/lib/sorter/controller.test.ts`.

**Interfaces (exact):**
```ts
export type SorterItem = { id: number; ms: number; name: string; scores: Score[]; url: string };
export type ArchiveView = {
  url: string; name: string;
  counts: { sorted: number; skipped: number; errors: number };
  failures: { source: string; error: string }[];
};
export type SorterSnapshot = {
  items: SorterItem[];
  pending: number;
  failure: string | null;
  progress: { loaded: number; total: number } | null;
  percent: number;
  loadingModel: boolean;
  archiveProgress: ArchiveProgress | null;
  archivePercent: number;
  archiveResult: ArchiveView | null;
  archiveBusy: boolean;
  busy: boolean;
};
export type SorterDeps = {
  classify(file: Blob, labels: string[]): Promise<{ scores: Score[]; ms: number }>;
  sortArchive(file: File, labels: string[], classify: ClassifyImage, onProgress: (p: ArchiveProgress) => void): Promise<SortArchiveResult>;
  createUrl(blob: Blob): string;
  revokeUrl(url: string): void;
  now(): number;
  uuid(): string;
  onSnapshot(snapshot: SorterSnapshot): void;
};
export type SorterController = {
  classifyFiles(files: readonly File[], labels: string[]): Promise<void>;
  sortArchiveFile(file: File, labels: string[]): Promise<SyncRun | null>;
  dispose(): void;
};
export function createSorterController(deps: SorterDeps): SorterController;
```
