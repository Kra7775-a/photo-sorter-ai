# UI Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать `src/lib/ui/*` — доступные компоненты на bits-ui и семантических OKLCH-токенах, готовые к миграции экранов.

**Architecture:** Каждый компонент — отдельный `.svelte` с `$props()`; `tv()`-рецепты лежат рядом с компонентом в `<script module>`; bits-ui отвечает за доступность/клавиатуру, стили — только токены из `src/app.css`. Барреля и общего `variants.ts` нет — импорт напрямую из `.svelte`-файлов.

**Tech Stack:** Svelte 5 runes, bits-ui 2.22.0, tailwind-variants 4.0.2, Tailwind v4, Bun.

**Spec:** `docs/superpowers/specs/2026-11-24-ui-kit-design.md`

## Global Constraints

- Bun только, точные версии; `bun run validate` — gate каждой задачи.
- Svelte 5 runes, `$props()`, keyed `{#each}`, `$bindable()` где нужно; не legacy-синтаксис.
- Только семантические токены из `src/app.css`; никаких hex/сырых цветов.
- Строки UI по-русски; код/комментарии/идентификаторы по-английски.
- Не трогать `src/App.svelte`, `src/lib/components/*`, engine/archive/sync/server (это отдельная миграция).
- Новых зависимостей нет: bits-ui и tailwind-variants уже установлены.
- `bun x @sveltejs/mcp svelte-autofixer` на всех новых `.svelte` — 0 issues.

## Review Focus

1. Контраст `text-on-accent` на всех акцентных вариантах и `text-danger` на `bg-danger-soft` в обеих темах → browser smoke.
2. Видимый focus-индикатор (ring-focus) на button/switch/tabs/dialog/input/textarea → browser smoke + autofixer.
3. Доступность_bits-ui: ARIA `aria-checked`, `aria-selected`, `role=alert`, desktop keyboard nav → browser smoke.
4. Отсутствие сырых цветов и случайных изменений других подсистем → `git diff` + validate.
